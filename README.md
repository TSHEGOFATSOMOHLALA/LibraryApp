# Library Management System

## The Vision
The Library Management System is a Django-powered web application built to bring structure and ease to everyday library record-keeping. Instead of relying on paper logs or disconnected spreadsheets, this project reimagines library management as a clean, organized digital workflow , making it simple to track every book, every author, and every member in one place.

## Features

- **Author Records** – Maintain a full list of authors with their details.
- **Book Management** – Register and manage books within the library collection.
- **Full CRUD Functionality** – Add, edit, update, and remove records with ease.
- **Authentication** – Secure login and sign-up flow to protect record management.
- **Clean, Responsive Interface** – A simple, distraction-free UI built for everyday library use.

## Technical Specifications

- **Framework:** Django (Python)
- **Database:** SQLite
- **Frontend:** HTML, CSS
- **Deployment:** PythonAnywhere
