Welcome to the Library Management System

This system helps libraries manage members and their borrowed books efficiently. You can use the system to maintain records of library members and the books registered in the collection.

System Features

  • Maintain a list of library members.
  • Register and manage books in the collection.
  • Update member and book information.
  • Remove records that are no longer needed.

Getting Started

Use the navigation menu above to view the available records in the system.

  • Authors – View, add, edit, or delete author information.
  • Books – View, add, edit, or delete book records.

About This System

The Library Management System is a simple web application built with the Django framework. It demonstrates how databases and applications can be used together to manage information in a library, including books, members, and borrowing records.
